# 接入小鲸鱼的能力

把插件的业务逻辑包装成一个适配器，在 [工具注册表](../bridge/tools.mjs) 的 `SKILLS` 中显式登记。现有的 `daily_fortune` 是完整示例。登记后，鲸鱼窝在「能力」页显示参数和使用范围，模型在获准的对话里可以调用它。

| 字段 | 用法 |
| --- | --- |
| `name` | 唯一的英文工具标识，建议用小写字母和下划线 |
| `desc` | 说明什么时候应调用，以及能返回什么 |
| `params` 和 `required` | 声明字符串、数字、整数或布尔参数，以及必填字段。可用 `enum` 与 `maxLength` 约束取值 |
| `skill` | 设置显示名称 `label`、分类 `category` 和可用渠道 `platforms` |
| `run(args, { platform, kind })` | 接收校验后的参数，返回 `{ ok: true, text }` 或 `{ ok: false, error }` |

`platforms` 可选 `qq`、`wechat` 和 `webui`，省略时三端可用。能力默认只对管理员开放。面向普通用户的功能可以设定 `audience: 'chat'`，同时遵守该渠道的会话准入。

对外写入或状态变更可以设定 `effectful: true`，用持久化调用记录避免同一轮失败重试时重复执行。结果无法确认时返回 `unknown: true`。凭据从服务端配置读取，聊天参数与结果只放获准在该会话使用的内容。

通用接口回传文字。图片、原生 QQ 事件和多轮会话按具体插件接入。依赖 NoneBot 的真寻插件可以抽取可复用的业务逻辑，再由适配器调用。
